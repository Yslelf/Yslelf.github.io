# XY 南昌开发路线

## Phase 1：探索原型（当前）

- 四栏导航：首页为探索，组局、消息、我的保持明确占位。
- 探索页支持搜索、分类、Feed、地图切换、下拉刷新。
- 使用 `mock.json`，service 层可切换 ASP.NET Core API。
- H5 和微信小程序构建通过。

验收重点：用户是否理解“真实地点体验”的定位，是否愿意打开地点和帖子继续浏览。

## Phase 2：X 内容闭环

- 地点详情、帖子详情、评论半屏层。
- 发布地点帖、媒体上传、草稿和审核状态。
- 收藏、想去、有用、点赞、现场打卡。
- ASP.NET Core Explore/Places/Posts API 与第一批数据库迁移。

完成标准：新用户可从浏览到发布完成一次闭环，运营能审核和处理内容。

## Phase 3：身份与可信资料

- 手机号/微信登录、基础 XY 名片。
- 认证流程、资料公开范围、身份分。
- 举报、封禁和申诉最小安全闭环。

## Phase 4：Y 组局

- 找局、详情、资料授权、报名审核、群聊、签到和结束反馈。
- 未成年人、信用与隐私规则必须先于开放组局上线。

## Phase 5：经济与运营

- XY 币、奖励任务、流水与预算。
- 管理后台、权限、审计和运营分析。

## Definition of Done

每个功能至少包含：正常/空/加载/错误状态、权限与隐私检查、API 契约、数据迁移、关键测试、埋点、文档同步和可回滚方案。
